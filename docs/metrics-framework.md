# Metrics Framework

指标用于帮助判断内容是否有效，但不替代内容判断。

## 核心指标

| 指标 | 说明 | 用途 |
| --- | --- | --- |
| 阅读量 | 文章打开次数 | 判断分发效果 |
| 读完率 | 阅读完成程度 | 判断结构和吸引力 |
| 分享数 | 被转发次数 | 判断观点传播性 |
| 收藏数 | 被保存次数 | 判断长期价值 |
| 留言数 | 互动数量 | 判断讨论潜力 |
| 新关注 | 发布后新增关注 | 判断转粉能力 |

## 质量指标

数据之外，每篇文章还要人工打分：

- 主判断是否清楚
- 开头是否有效
- 例子是否具体
- 结构是否顺
- 是否保留主理人语气
- 是否值得三个月后再看

## 复盘问题

每篇文章发布后回答：

- 读者为什么点进来
- 读者为什么愿意读完
- 哪一句最可能被记住
- 哪个部分拖慢了阅读
- 这个选题是否值得追踪
- 下一篇可以接什么
