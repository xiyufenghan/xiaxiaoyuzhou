# Weekly Review Workflow

## 时间

建议每周固定一次，最好在下一周选题前完成。

## 输入

- 本周发布文章
- 公众号后台数据
- 留言和私信反馈
- 本周新增素材
- 主理人自己的感受

## 输出

- 本周内容判断
- 可复用经验
- 需要修正的栏目节奏
- 下周选题计划
- 需要沉淀的资料或片段

## 操作

1. 更新 `data/metrics/weekly-review.md`。
2. 使用 `prompts/weekly-review.md` 生成复盘。
3. 把有长期价值的发现写入 `docs/decision-log.md` 或 `data/research/`。
4. 更新下周 `content/calendar/`。
