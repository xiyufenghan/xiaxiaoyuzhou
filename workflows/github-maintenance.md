# GitHub Maintenance Workflow

## 目标

保持 repo 可以长期协作、检索和迭代。

## 每次较大更新后

1. 检查新增目录是否有 README。
2. 检查文档是否为 Markdown。
3. 运行项目校验脚本。
4. 查看 Git 状态。
5. 用清晰提交信息提交。

## 建议提交类型

- `docs:` 文档更新
- `content:` 内容草稿或发布稿
- `data:` 指标或素材更新
- `prompts:` 提示词更新
- `agents:` Agent 角色更新
- `scripts:` 自动化脚本更新
- `workflow:` 流程更新
