# Publishing Workflow

## 公众号发布流程

1. 准备定稿。
2. 确认栏目。
3. 选择对应模板：
   - 浴缸速记 / 奇闻浴场：日常轻量版
   - 老A的判断：结构长文版
   - 世界正在变化：周报 / 月报版
4. 使用 `公众号发布包/给Codex或ChatGPT的排版提示词.md` 生成 HTML。
5. 打开 HTML 预览。
6. 复制正文区域到公众号编辑器。
7. 检查手机预览。
8. 填写标题、摘要、封面和原创信息。
9. 发布后记录数据入口。

## 发布前检查

- 标题没有误导
- 摘要不重复标题
- 正文顶部不重复大 Logo 和标题
- 没有 Markdown 草稿符号
- 没有未处理的「待核查」
- 手机预览段落间距正常
