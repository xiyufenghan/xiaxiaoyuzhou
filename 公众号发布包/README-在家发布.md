# 《浴缸里的小宇宙》公众号发布包

这个文件夹可以复制到家里的电脑、网盘、U 盘、iCloud Drive 或飞书云文档里使用。

## 文件结构

- `templates/`
  - 三套公众号 HTML 模板
- `assets/`
  - 四个栏目 Logo 图片
- `公众号排版规范-v1.md`
  - 排版规则说明
- `给Codex或ChatGPT的排版提示词.md`
  - 以后发文章时可直接复制使用

## 推荐发布流程

1. 在公众号后台上传封面图、填写标题和摘要。
2. 把文章正文发给 Codex 或 ChatGPT，并附上栏目、期数、标题。
3. 让它按照本发布包里的规范输出 HTML。
4. 打开生成的 HTML，复制正文区域到公众号编辑器。
5. 在公众号编辑器里检查手机预览。

## 注意

公众号正文里不要重复大 Logo 和文章标题。

封面负责品牌识别，正文负责阅读体验。
