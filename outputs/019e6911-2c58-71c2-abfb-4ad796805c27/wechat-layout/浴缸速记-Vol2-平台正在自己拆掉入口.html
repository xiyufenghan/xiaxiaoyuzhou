平台正在自己拆掉入口

老A · Vol.2 · 浴缸速记

洗澡、散步和深夜发呆时冒出来的问题。
记录尚无答案、但值得思考的小念头。
“

平台不再争夺入口，
而是在争夺成为 Agent 背后的能力层。

“

昨晚刷到一个消息：Meituan 发布了跑腿 Skill。

第一反应不是“又一个 AI 功能”。而是——平台开始亲手拆自己的入口了。

因为这不是孤立事件。

同一阶段里：

• 美团把跑腿能力做成 Skill，开始向 Agent 暴露能力；

• AutoNavi 在做 ADQ API，把地图、导航、出行能力抽出来；

• JD.com 也在逐渐开放物流、履约、零售能力；

• Harness 开始推 agentic workflows，本质上是在让 AI 直接编排企业流程。

看起来行业不同，但方向是一样的：

老A的判断

平台不再争夺入口，而是在争夺成为 Agent 背后的能力层。

01

App 不再是目的地

以前的平台逻辑是：

用户 → App → 下单 → 平台履约。入口属于 App，谁占据首页，谁拿走流量。

但 Agent 时代开始变成：

用户 → Agent → 调度能力 → 完成订单。入口消失了，App 不再是目的地，而是能力仓库。

这时候最危险的事，不是别人拆你，而是你还没来得及拆自己。

所以现在看到的平台动作很有意思：在被“无头化（Headless）”之前，先主动把自己无头化。

放弃 App 独占入口，把能力开放给 Agent。因为未来失去一个前端入口，可能换回来十个 Agent 后台的自动订单。这不是防守，这是提前迁移。

02

流量玄学开始失效

但这个迁移背后，藏着一个极度残酷的底层逻辑改变：

当所有的流量运营套路，撞上绝对理性的 AI，全都失效了。

以前在 App 里，平台可以搞满减凑单、搞内容种草、搞千人千面的算法，靠“信息差”和“情绪价值”提高利润。

现在的 Agent 就像一个冷酷的、没有感情的采购员。它调取能力时，不看你的界面有多好看，只看最硬核的物理指标：

谁的响应快了 2 秒？

谁的履约成本低了 2 毛钱？

谁的 API 报错率低了万分之一？

互联网竞争，终于从花哨的 “前端流量玄学”，回归到了沉重的 “后端物理实力”。

03

Agent 改变的是交易

突然理解了王兴那句话：

“AI Agent 对我的冲击，比 ChatGPT 更大。”

因为 ChatGPT 改变的是知，或者说搜索。

Agent 改变的是行，或者说交易。

而交易，才是平台真正的命。

04

你自己的入口，也该重打包了吗？

最后的一点冷思考：

巨头们已经开始拆掉 App 卖能力了。

那么我们自己呢？

你死守的那个“岗位、title 或信息差入口”，是不是也到了该亲手拆掉，重新打包成 API 的时候了？
