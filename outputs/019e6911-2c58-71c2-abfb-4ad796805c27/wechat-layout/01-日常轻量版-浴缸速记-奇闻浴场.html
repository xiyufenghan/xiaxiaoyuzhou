浴缸速记 · Vol.2

昨晚刷到一个消息：Meituan 发布了跑腿 Skill。

第一反应不是“又一个 AI 功能”。而是——平台开始亲手拆自己的入口了。

因为这不是孤立事件。同一阶段里，美团把跑腿能力做成 Skill，AutoNavi 在做 ADQ API，JD.com 也在逐渐开放物流、履约、零售能力。

平台不再争夺入口，而是在争夺成为 Agent 背后的能力层。

以前的平台逻辑是：用户 → App → 下单 → 平台履约。入口属于 App，谁占据首页，谁拿走流量。

但 Agent 时代开始变成：用户 → Agent → 调度能力 → 完成订单。入口消失了，App 不再是目的地，而是能力仓库。

这时候最危险的事，不是别人拆你，而是你还没来得及拆自己。
