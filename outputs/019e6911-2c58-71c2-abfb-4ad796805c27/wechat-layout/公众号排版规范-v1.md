# 《浴缸里的小宇宙》公众号排版规范 v1

## 基本原则

公众号后台已经有封面、标题、作者和摘要，所以正文 HTML 不再重复大 Logo 和大标题。

正文只负责阅读体验：开头直接进入内容，栏目识别要轻，不要像海报或网页落地页。

## 三类模板

### 1. 日常轻量版

适用栏目：
- 浴缸速记
- 奇闻浴场

适用内容：
- 日常短思考
- 灵感速记
- 小故事、小念头、小判断

排版规则：
- 不放大 Logo
- 不重复文章标题
- 不放完整栏目说明卡
- 开头可放一个很轻的小标识，也可以直接进入正文
- 只保留 1 个重点判断卡
- 不使用大段目录和多级章节

模板文件：
- `01-日常轻量版-浴缸速记-奇闻浴场.html`

### 2. 结构长文版

适用栏目：
- 老A的判断

适用内容：
- 有事实、推演、修正、判断的长文
- 行业判断
- 商业或平台变化分析

排版规则：
- 不放大 Logo
- 不重复文章标题
- 栏目名融合进说明卡，作为左上角眉标
- 可以使用章节编号：01 / 02 / 03
- 可以使用“老A的判断”卡片
- 可以有 END 模块

模板文件：
- `02-结构长文版-老A的判断.html`

### 3. 周报 / 月报版

适用栏目：
- 世界正在变化

适用内容：
- 每周观察
- 每月变化总结
- 多个变化信号合集

排版规则：
- 不放大 Logo
- 不重复文章标题
- 栏目名融合进说明卡，作为左上角眉标
- 保留目录模块
- 保留“本期总判断”
- 每个变化信号使用统一结构：发生了什么 / 为什么重要 / 可能影响谁

模板文件：
- `03-周月报版-世界正在变化.html`

## 投稿给 Codex 时的推荐格式

直接把正文发过来，并在开头标注：

```text
栏目：浴缸速记 / 老A的判断 / 世界正在变化 / 奇闻浴场
期数：Vol.x（如果有）
标题：文章标题
是否需要保留原文语气：是 / 否

正文：
...
```

如果没有标注栏目，Codex 根据内容判断：
- 短念头、灵感、临时观察 → 日常轻量版
- 有逻辑推演和明确判断 → 结构长文版
- 多条趋势、周报、月报、信号合集 → 周报 / 月报版
- 故事、怪谈、历史奇闻、人类行为 → 日常轻量版的奇闻浴场变体

## Codex 输出要求

每次输出：
- 一个可直接打开预览的 HTML 文件
- 清理草稿痕迹，比如“升华新增部分”、Markdown `**`
- 保留作者原有语气，但优化段落节奏
- 不把正文排成一句一行
- 不在正文顶部重复公众号标题和封面内容
